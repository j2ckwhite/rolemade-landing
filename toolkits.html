AI toolkits

Private tools for the jobs you'd rather hand off.

A toolkit is a set of private tools, each built for one task and one person, living on your own address. Our prompting and your standards are built into every one. This page covers what's inside, how a build runs, and what it costs you.

What's inside

Small tools. One job each.

Nothing here is a platform and nothing here is a chatbot. Each tool does one thing you already do, the way you already do it, and stays out of the way otherwise.

01

One tab per task

Your toolkit is a single page with a tab for each task. Open the tab, do the job, close it. No menus to learn.

02

Your standards, built in

How you check the work, the format you deliver in, the things you always flag. We write all of it into the tool once, so the output comes out the same way every time without anyone typing a prompt.

03

Drop in, get back

A file, a set of notes, a filled-in form. The finished work comes out. If something in the input doesn't look right, the tool tells you instead of guessing.

How a build runs

Free sample first. Then the toolkit.

You're involved at the start and at the end. The middle is ours.

Step 1

Free sample

Send one real example of a task you repeat. We build the first tool and you run it on your own input. No call required, nothing paid.

Step 2

Walkthrough and build

If the sample is useful, we spend an hour on a screen share going through the rest of your week. We pick the next tasks, agree on three past examples for each, and build against them.

Step 3

Live on your domain

The toolkit goes live on your own address and stays there. We keep it running, fix what breaks, and add tools as new jobs come up.

What it connects to

Not only files.

Most first tools are file in, file out. They don't have to stay that way.

Spreadsheets, PDFs, Word docs, meeting notes, filled-in forms, pasted emails.

Outputs

The finished work in the Excel, Word, or PDF layout you already send, not a generic export.

Connections

Tools can pull from and push to Gmail, Google Drive, spreadsheets, and most software with an API.

Schedules

A tool can run on its own each Monday morning and leave the result waiting for you.

Private by design

Some never send the file anywhere

Tools that sort, match, or reformat run entirely in your browser. The file never leaves the machine.

People

One person or a team

Built for the person doing the task first. Shared with the team on the same address when it should be.

Consulting

Not sure where it fits? We map it.

Most people can't see their own repetitive work. It's just Tuesday. So before anything gets built, we sit down and go through a normal week with you: what comes in, what you do with it, what goes out, and who's waiting on it.

You leave with a short ranked list. Each task gets a plain answer: worth building now, worth it later, or not a fit. That's the whole deliverable. No deck, no roadmap, no follow-up sequence.

If nothing on the list is worth building, we'll say that too.

Questions

Things people ask first

Do I need to learn anything?+
No. If you can attach a file to an email, you can use the tool. That's the standard we build to, and we test it by handing the tool to someone with no explanation and watching.
What happens to my files?+
They're used to produce the output and nothing else. Tools that sort, match, or reformat run entirely in your browser, so the file never leaves your machine. Tools that need the model send the file to it under commercial terms that don't allow training on your data. Before we build, we tell you which kind each tool is, in plain language. If you have a rule about where data can live, we build around it.
What if the task changes?+
Small changes get folded in during the handoff period. Bigger changes are a short follow-up build. Tools are meant to be adjusted as your work does.
Can more than one person use it?+
Yes. We build for the person doing the job first, because that's what keeps it simple. If a team shares the task, the toolkit is set up for that team on its own address.
What does it cost?+
The first tool is free. After that there is a one-time build fee for the toolkit, and a flat monthly fee to keep it live on your domain, maintained, and growing with new tools as you find new jobs. You get the numbers before any paid work starts. No hourly billing, month to month, stop whenever you like.
What if the tool gets it wrong?+
Before we build a paid tool, we pick three real past examples together and agree on what the correct output was. The tool passes when it reproduces them. If it doesn't pass, there's no build fee. Once it's live, anything that drifts gets fixed as part of the monthly fee.
Is this just ChatGPT with a wrapper?+
ChatGPT is a blank box that waits for you to explain what you want, every time. A toolkit already knows. Your steps, your format, your checks are built in, and the input is a file, not a conversation.
